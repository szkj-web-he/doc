# 什么是 webSocket

websocket 是计算机通信协议的一种,也就是 http 请求的升级版.很明显的特征就是当我们建立 socket 链接的时候,会返回一个 101 的状态码,我们都知道 101 表示切换协议.
它不同于 http 协议的是,它是双向通讯且不需求在每次传输数据时重新建立链接

我们都知道 OSI 模型为 7 个

1. 物理层
2. 数据链路层
3. 网络层
4. 传输层
5. 会话层
6. 表现层
7. 应有层
   那我们的 TCP/IP 协议其中存在于
   数据链路层,网络层,传输层,应有层
   而我们的 http 就在应用层.相应的 websocket 也就在这一层.
